# Feliz aniversário, Celeste!

Site estático de uma página, pronto para GitHub Pages.

## Publicação

1. Crie um repositório no GitHub.
2. Envie `index.html`, `styles.css`, `script.js` e a pasta `assets` para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde o link público aparecer.

## Ajustar a data da amizade

No começo de `script.js`, altere `FRIENDSHIP_STARTED_AT`. A versão atual usa **19/09/2026 às 12:50**, no horário de Brasília.

O projeto não usa bibliotecas externas nem processo de build.
